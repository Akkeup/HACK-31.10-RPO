# Модели из `асеты.zip`

Исходные GLB сохранены с именами, соответствующими объектам проекта:

| Файл | Объект |
| --- | --- |
| `reading-shelf.glb` | стойки с книгами |
| `reading-desk.glb` | стол с тетрадями |
| `competition-table.glb` | стол в центре зала |
| `teacher-mathematics.glb` | учитель математики |
| `teacher-informatics.glb` | учитель информатики |
| `teacher-history.glb` | учитель истории (`Учиталь истории` в архиве) |
| `teacher-geography.glb` | учитель географии |
| `npc-examiner.glb` | экзаминатор |

Три файла с суффиксом `-runtime` — уменьшенные копии моделей мебели. Стойка и
письменный стол публикуются в демонстрационном мире. Центральная модель из
архива имеет продолговатую столешницу; для пяти мест в прототипе используется
отдельная круглая модель из `apps/client/public/assets/models/furniture/`.
Исходные файлы сохранены для повторной подготовки моделей.

Модели персонажей не входят в потоковый каталог мира: в автономном mock-режиме
одна модель преподавателя и модель экзаменатора загружаются из локальных
`/assets/models/` как демонстрационный визуальный слой. Это не проверка лимита
production-манифеста. Для серверной интеграции их нужно подготовить и
опубликовать в interest с пересчётом хешей и бюджета.
