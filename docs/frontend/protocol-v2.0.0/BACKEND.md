# Backend: контракт будущей интеграции

Rust/Axum/Tokio/Serde/SQLx/PostgreSQL18; сохранить текущую архитектуру. Авторитетные позиции/коллизии, seats, попытки, вопросы, оценки, аура и права. Frontend пока не подключён: реализация backend может проверяться fixtures независимо, обязательного LLM для старта нет.

Публикуемые local knowledge modules/facts/books/questions имеют стабильные IDs, contentVersion, provenance и статусы draft/reviewed/published. Только published используются в настоящей игре. Данные fixtures синтетические, не готовая проверенная библиотека. Реальный flag dataset уже есть у команды: сделать отдельный importer adapter с явным mapping полей, не менять исходник, не придумывать его путь/структуру. Подготовка может использовать интернет, runtime — нет. LLM получает только отобранные короткие локальные факты; не обладает доступом к произвольному SQL и не хранит прохождение.

Типы вопросов/ответов — education/answer schemas. Совпадение kind проверяет backend. single_choice проверяется по закрытому optionId; numeric безопасно разбирается как ограниченная десятичная строка (поддержать точку/запятую, отказать NaN/Infinity/выражения), сравнить с tolerance; short_text/flag_country — Unicode normalize NFKC, trim, casefold при caseSensitive=false, нормализация повторных пробелов, проверенные aliases. Нечёткое совпадение не даёт автоматический балл. explanation — rubric/учебная обратная связь, feedback_only, correct=null, без автоматического балла. LLM feedback никогда не определяет выплату.

Attempt хранит current/sequence/shown/answered/family IDs, module/content/config revision, score, questionCount, scoredQuestionCount, passScore и статус. passScore<=scoredQuestionCount<=questionCount; result.maximumScore=scoredQuestionCount. На production вопрос/семейство не повторяется внутри attempt. Семантические перефразирования в одном family. Недостаточно опубликованных разных family — отказ запуска, не генерация похожего вопроса в момент ожидания.

quiz.leave и disconnect grace expiry теперь suspended, а не interrupted. Стул освобождается при leave сразу, после disconnect через60с. Попытка живёт отдельно от seat lease. По умолчанию suspended сохраняется до явного resume/abandon или завершения; logout не удаляет. Resume проверяет владельца, pinned contentVersion, свободный подходящий стул/дистанцию, атомарно занимает место и восстанавливает active/feedback. Уже решённые задания не повторяются, неотвеченный вопрос тот же. Restart безопасно переводит незавершённые quiz в suspended. quiz.abandon — явное terminal interrupted без зачёта, с предупреждением UI. Уникальность незавершённой попытки (user,module,contentVersion) не даёт обходить повторения новым quiz.start.

library.open(bookId) проверяет доступ/дистанцию к полке и даёт library.opened с lessonId/material. lesson.close закрывает и сохраняет viewed. lesson.open(npcId) сохраняется для teacher. country.describe разрешён у teacher geography_flags, возвращает опубликованные 3–4 предложения, без вызова модели при каждом посещении. В learning activity.targetId может быть bookId или teacherId; seatId=null.

Конкурентные ответы/seat/команды сериализованы транзакцией и доменными UNIQUE. Сначала command idempotency lookup, затем CAS/права, затем commit и outbox. Повтор requestId — тот же результат, другой payload — REQUEST_ID_REUSED. Ключи/aliases/банк не выдаются frontend. Зафиксированная версия контента доступна попытке даже после обновления публикации. GET attempt возвращает владельцу состояние без повторного исполнения.

Соревнования:2–5, одинаковая ставка, банк=N*stake,5 вопросов/20с default. Типы допускаются только objectively graded: numeric, short_text, flag_country, single_choice; explanation запрещён. Winner получает bank, tied best возвращает stake всем, cancellation тоже. Holds/escrow/ledger/settlement атомарны и идемпотентны; баланс100 выдаётся один раз. Лобби и seat lease отдельно от durable attempt. При restart running match отменяется с одним возвратом. Полные правила base приведены в GAMEPLAY_V2.
