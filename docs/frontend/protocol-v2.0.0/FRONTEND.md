# Frontend: самостоятельный прототип

JavaScript ES Modules + Three.js + существующая структура клиента, без TypeScript. По умолчанию transport=mock; запуск клиента не требует login, PostgreSQL, LLM и сетевого сервера. Интерфейс не должен пытаться вызвать реальные API на старте. mock/core.mjs реализует connect/send/onMessage/close и читает локальные fixtures. Browser wrapper использует fetch локальных файлов, Node wrapper — файловую систему. Смена transport в одном месте заменяет адаптер на network, компоненты сцены не импортируют mock keys напрямую.

Зал: светлое дерево, спокойные цвета и мягкий свет; 4 тематические секции mathematics, informatics, history, geography_flags. Полка выбирает книгу, преподаватель объясняет, тетрадь запускает проверку, круглый стол в центре на5 мест запускает соревнование. Первоначально простые формы и модели-заглушки, потом GLB/glTF через assetSlots. Все позиции/масштабы в конфиге, проходы свободны. Полный real flag dataset не импортировать и не переделывать на этом этапе.

Первое лицо: WASD, мышь/Pointer Lock после клика, ограниченный pitch, прицел, E-взаимодействие. Собственная модель не закрывает обзор, другие видны. При panel/input: нулевое намерение движения, курсор свободен, WASD вводит текст, не двигает игрока. Escape только меню/курсор. Возврат через явное действие. Подсказки: изучить материал, поговорить, начать проверку, занять место. В mock посадку подтверждает адаптер; в production — сервер. Камера плавно садится/встаёт после activity.changed, другие видят seated mode.

Книги/учитель: удобный HTML/CSS текст поверх живой сцены. Загрузка/ошибка/пустое состояние обязательны. country.description содержит 3–4 предложения; выводить textContent, не HTML. Не дописывать факты на frontend. Нынешняя country карточка намеренно вымышленная и обозначена «Демо».

Тетрадь: ordinal/questionCount, prompt, поле ответа, отправить, подтверждение, explanation, далее, итог/встать. По kind: numeric — текстовое поле с inputmode decimal (не вычислять выражения); short_text и flag_country — строка; explanation — textarea; single_choice —4 варианта. Набранный ответ превращается в {kind,value}, все value строки. После отправки блокировать повтор. При feedback_only показывать учебную обратную связь без отметки верно/неверно и без начисления балла. Ни ключ, ни expectedAnswer до ответа в production не известны клиенту.

Уход quiz.leave сохраняет suspended, место освобождается; возврат quiz.resume после подтверждения места восстанавливает тот же attemptId, current question или feedback. Новая попытка по отдельному явному действию после завершения/abandon. localStorage допускается лишь для demo snapshot, без токенов и реальных ключей; при network-mode его нельзя принимать за серверную истину.

Флаги: пока локальный SVG-заполнитель и вымышленная страна, никаких загрузок реального датасета/CDN. Сохранять пропорции, alt нейтральный, не раскрывать ответ в URL/title/filename. Для production потребуется backend adapter существующего датасета, а не новый набор. Asset IDs непрозрачны, country aliases закрыты.

Стол: виртуальные участники в mock, пометка «Демо». Показать состав, готовность, тему, ставку, available/reserved aura, вопрос/таймер/итог. Финансовые исходы mock независимые иллюстрации, не настоящий multiplayer. UI предусматривает занятость, недостаток денег, победу/поражение/ничью/отмену. Network-state и расчёты в будущем только от сервера.

Зависимости/ресурсы локальные. Переиспользовать мебель/текстуры, освобождать Three.js ссылки/dispose. Флаги загружать по одному. Декоративная художественная сцена проверяется отдельно от фикстур, максимум логического контента C+R<=floor(W/10). Пока нет настоящего server manifest, бюджет UI явно demo и не объявляется production проверкой.
