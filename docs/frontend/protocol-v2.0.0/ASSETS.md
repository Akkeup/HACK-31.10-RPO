# Ассеты и визуальные заглушки

Reading room минимально требует: стеллаж, книги, письменный стол, стул, открытая тетрадь, круглый стол, NPC/игрок, idle/walking/sitting animations. Текущий model-triangle и assetSlots placeholder=true лишь проверяют контракт. Найденные GLB/glTF должны иметь локальные textures/decoders, известную лицензию/автора, согласованный масштаб и один визуальный стиль. Сначала graybox/проходы/взаимодействия, потом финальные модели.

Человек может подобрать модели отдельно; замена через assetSlots/modelId и опубликованный content catalog, не переписывание UI/игровой логики. При замене пересчитать SHA/byteSize/W, collision/nav и seat/exit. Все игровые модели и флаги включать в единый учёт C+reserved<=floor(W/10). Не прятать геометрию в JS, metadata или бесконтрольный browser cache. GPU/RAM отдельно ограничиваются и измеряются на целевом устройстве. В prototype budget обозначен demo, реальные показатели не заявлены.
