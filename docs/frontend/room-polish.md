# Кабинеты: исправления визуального прототипа

Следующий этап выполнен: [комплект новых моделей и аватар игрока](assets-pack-2.md).
Список недостающих ассетов ниже относится к состоянию до получения второго архива.

Локальная проверка: `VITE_TRANSPORT=mock npm run dev`, текущий адрес
`http://127.0.0.1:5291/`. Для полного повторного запуска браузерной проверки
откройте `/?roomqa=1`. Для осмотра конкретного кабинета в DEV доступен
`/?academy-view=room-informatics` (также room-mathematics, room-history,
room-geography). Эти средства работают только в mock и исключены из production.

## Поведение сцены

- Повторяющиеся пункты «Примеры»/«Главное» показываются один раз; уникальные
  пункты сохраняются. Карточки по-прежнему содержат до четырёх строк.
- Поворот NPC больше не сбрасывается snapshot. Позиции интерполируются,
  поворот сглаживается между кадрами. В mock преподаватель и экзаменатор
  гуляют по разным свободным маршрутам со скоростью 1.1 м/с, делают паузы,
  останавливаются рядом с игроком и во время занятия. Real использует
  только координаты NPC сервера; новых WS-команд не введено.
- У текущих humanoid GLB есть скелет, но нет клипов. Для них применяется
  процедурный шаг ног и рук, фаза зависит от пройденного расстояния.
  В покое нет качания/шума; авторские клипы, если появятся, имеют приоритет.
- Надписи выхода направлены внутрь кабинета. Canvas-текстуры учитывают
  пропорции табличек, текст вписывается изменением размера шрифта,
  без горизонтального растяжения. Имена прозрачные, жирные, двухстрочные,
  с тёмным контуром. Текстуры используют mipmaps и anisotropic filtering.
- В кабинете одна учебная полка и один стол проверки со стулом; отдельный
  преподавательский стол содержит только тематические предметы и лампу.
  В информатике один компьютер, стоящий на преподавательском столе.
- Излишние встроенные в прежнюю модель стола книги/лампы убраны вместе
  с её заменой чистой геометрией стола. Тетрадь — рисунок в материале
  столешницы. Отдельные модели книги/тетради не загружаются через LocalArt,
  опубликованные старые отдельные props скрыты. Их серверные ID/контракты
  сохранены: чтение вызывается у полки через library.open, проверка — у
  стола через quiz.start/resume. Неизменяемые ресурсы не перепубликовывались.
- Все импортированные стулья дополнительно развёрнуты на 180 градусов;
  серверные seat transforms и камера посадки не менялись.
- У выхода временная деревянная дверь с ручкой и табличкой. Неиспользуемый
  проём в задней стене общего зала закрыт материалом стены, белый фон не виден.

Потоковый ResourceLedger и его лимит не менялись. Дополнительный слой
LocalArt по-прежнему имеет ограничения учёта из protocol-v2-audit.md.

## Какие ассеты ещё нужны

Для замены оставшихся визуальных заглушек, а не для загрузки приложения:

1. Дверь с коробкой в GLB, желательно с отдельной створкой и pivot на петле.
   Без запечённых надписей — русские подписи рисует клиент. Одна модель
   переиспользуется во всех кабинетах; текущий проём около 2.6×3.2 м.
2. Чистый письменный стол без встроенных ламп, книг, компьютеров и стульев,
   чтобы состав кабинета можно было контролировать. Сейчас используется
   процедурный стол шириной 2.1–2.3 м и высотой столешницы около 0.9 м.
3. Компьютер/монитор с клавиатурой как один небольшой GLB для замены
   процедурного рабочего места в информатике.
4. София и общий персонаж игрока, если требуется заменить оставшиеся
   геометрические модели в общем зале. Преподаватели и экзаменатор уже есть.
5. К существующим скелетам — клипы Idle и Walk (in-place), а для игроков
   Sitting/StandUp. Это нужно для более естественного шага и посадки;
   текущая процедурная ходьба не заменяет полноценную авторскую анимацию.

Полка, стул, лампа, круглый стол и четыре преподавателя уже загружаются.
Отдельные GLB книги и тетради не нужны. Доска/таблички могут оставаться
кодовой геометрией: внешний ассет для них не обязателен. Все GLB должны
быть самодостаточными, в метрах, с основанием на y=0, без внешних URL.

модели и Canvas-текстуры в этот логический счётчик не включены.
