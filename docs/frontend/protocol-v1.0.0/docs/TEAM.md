# Параллельная разработка

Разработчик 1 владеет `apps/server/**`, `services/ai/**`, `infra/**`, миграциями, серверными наборами знаний NPC и `docs/backend/**`. Реализует Axum HTTP/WSS, игровые комнаты, авторизацию, симуляцию, выдачу ресурсов, PostgreSQL 18, конфигурации, локальные NPC и Windows Docker. Не меняет клиент и визуальные ассеты.

Разработчик 2 владеет `apps/client/**`, `assets/world/**`, `assets/models/**`, `assets/textures/**`, `docs/frontend/**`. Реализует JavaScript без TypeScript, Three.js, камеру, управление, интерполяцию, вход, диалоги, учёт ресурсов и панель настроек. Не меняет сервер, миграции, Docker и внутренний AI. Подготовленные модели и мир передаются серверному разработчику через неизменяемый контентный выпуск: сервер валидирует каталог, коллизии и контрольные суммы до активации.

Общий каталог `packages/protocol/**` изменяется только после проверки обоими участниками. Оба используют один ZIP и VERSION; целостность сравнивают по SHA256SUMS. Схемы не генерируются независимо из Rust и JavaScript.

Этап 1: первый разработчик реализует login, bootstrap, комнаты и ticket; второй строит сцену, login и сетевой адаптер на mock. Этап 2: первый реализует авторитетный input и snapshot; второй — предсказание, коррекцию и загрузку interest. Этап 3: первый реализует конфигурации и NPC; второй — диалоги и редактор. После каждого этапа подключают реальный backend через смену base URL, сохраняя форматы сообщений.

Backend отдельно проверяет Serde на fixtures, размеры сообщений, авторизацию, конкурентный join и транзакции. Frontend отдельно проверяет mock/demo.mjs, лимит ресурсов, освобождение Three.js объектов, локальные настройки и переключение origin. Общий рубеж: два разных браузера на LAN, затем пять игроков, затем отключённый интернет.

На первом общем созвоне достаточно утвердить VERSION, имя/адрес LAN-сервера, способ доверия TLS CA и конкретный каталог модели мира. В данном комплекте все остальные необходимые параметры имеют рабочие значения. Визуальный редактор размещения мира может быть отдельным этапом, но его данные уже представлены в admin WorldConfig; публикация геометрии требует нового контентного выпуска.
