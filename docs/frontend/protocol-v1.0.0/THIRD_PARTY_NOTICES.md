# Included JavaScript dependencies

Offline validation dependencies are redistributed under their upstream licenses. Every package retains LICENSE/NOTICE files in node_modules. Ajv 8.17.1, ajv-formats 3.0.1, yaml 2.8.1 and their pure-JavaScript transitive dependencies are included. ws 8.18.3 is included for optional developer WebSocket tooling; this release uses in-memory fixture adapters. No native binaries, game models or third-party knowledge packs are required. package-lock.json records exact package versions and integrity hashes. Node.js runtime is not bundled.
