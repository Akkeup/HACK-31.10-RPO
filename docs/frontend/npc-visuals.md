# Полупрозрачные диалоги и образы NPC

Окна урока, опроса, соревнования и диалога Софии используют фон с непрозрачностью 76–78% без дополнительного размытия. Карточки внутри тоже полупрозрачны; текст и интерактивные элементы остаются непрозрачными. Общая затемняющая подложка ослаблена, размытие всего экрана убрано.

Оригинальные модели без внешних текстур собраны в `assets/models/scholar.glb`:

- История: фараон в льняном одеянии, с сине-золотым немесом, широким воротником и скипетром.
- Математика: учёный в фиолетовом костюме, с очками, книгой и чертёжным треугольником.
- Информатика: преподаватель в бирюзовой куртке, с гарнитурой и планшетом.
- София: проводник с шарфом, книгой и сумкой.
- Общий экзаменатор: академическая мантия, конфедератка и золотой палантин.

`CharacterVisualConfig.npcModelId` по-прежнему выбирает GLB (`scholar` по умолчанию). Внутри него группы помечены `extras.npcAppearance {role, moduleId, npcId?}`. Клиент проверяет типы меток и выбирает одну группу по подтверждённым сервером роли и модулю; точный npcId имеет приоритет для Софии. Неизвестному профилю назначается образ проводника. Разрешённые GLB без таких меток работают как прежде. Новый предмет требует добавления группы в арт-файл, а не изменения сетевых схем.

Все пять образов используют общую геометрию и материалы одного GLB размером 34388 байт. Модель подключается через опубликованный каталог/interest и учитывается в ResourceLedger по SHA-256. Стол и стул оптимизированы повторным использованием геометрии: 7536 и 2972 байта. W=3076902, B=floor(W/10)=307690. Лимит не увеличен. Публикация: `npm run world:publish`; для реального сервера нужно опубликовать обновлённый каталог и ресурсы.

Проверка `tests/npc-appearance.test.js` декодирует настоящий вложенный GLB и проверяет единственный видимый образ для каждого профиля. DEV `/?educationqa` дополнительно проверяет образы в живом мире, прозрачность карточки и прежние сценарии кнопок/закрытия. Для обычной игры используется `/` без QA-параметров.

Проверено: 32 unit-теста, HTTP/WS integration и 11/11 браузерных сценариев. В браузере C∪R=294546 ≤307690 байт, декодированная память с экземплярами — 1693015 байт. Визуально проверены фараон, преподаватель информатики, экзаменатор и карточка истории. Замер кадров на нагруженной машине нестабилен и не подтверждает производительность на всех ноутбуках; дополнительное размытие панелей в итоговой версии отключено.
