# Discovery — браузерный клиент 2.0.0

[Новые модели и аватары участников LAN](assets-pack-2.md).

Переход на реальный сервер: [проверка backend и блокеры](backend-readiness-2026-11-01.md),
[HTTPS/WSS и сертификаты](tls.md). Текущие backend-блокеры не позволяют
объявить проект готовым к публичному запуску.

Из `apps/client`:

```sh
npm run build:real
npm run build:mock
npm run check:release
npm run check:backend
```

`check:release` проверяет клиентские тесты и обе изолированные сборки.
`check:backend` — отдельная живая проверка API/WS; ошибки и пропущенные
авторизованные проверки дают ненулевой exit code. Успех первого не означает
успех второго. Нужные переменные окружения описаны в проверке backend.

Активный клиент: JavaScript ES Modules, Three.js, Vite. Контракт —
**Discovery Protocol 2.0.0**, HTTP `/api/v2`, WebSocket `discovery.v2`,
`protocolVersion: "2.0.0"`. Автоматического перехода на 1.x нет.
Официальные схемы находятся в `apps/client/src/protocol/v2.0.0`,
документы спецификации — в [protocol-v2.0.0](protocol-v2.0.0/README.md).

## Запуск

Нужен Node.js 22.12+; зависимости установите заранее:

```sh
cd apps/client
npm ci
```

По умолчанию выбран **real**, как и в общем серверном запуске проекта.
Для Vite с прокси на локальный Rust:

```sh
VITE_TRANSPORT=real DISCOVERY_BACKEND_URL=http://127.0.0.1:8080 npm run dev
```

Самостоятельная демонстрация без Rust, базы и авторизации:

```sh
VITE_TRANSPORT=mock npm run dev
```

Адрес Vite: `http://127.0.0.1:5173/` (если порт занят, фактический адрес
показывается в терминале). Настройки также можно задать в `.env.local`
по примеру `apps/client/.env.example`. Значения кроме `real` и `mock`
отклоняются при запуске сборщика.

## Сборка и проверки

```sh
npm test
npm run test:integration
VITE_TRANSPORT=real npm run build
node tests/verify-bundle.js dist
VITE_TRANSPORT=mock npm run build -- --outDir dist-mock
node tests/verify-bundle.js dist-mock
VITE_TRANSPORT=mock npm run preview -- --outDir dist-mock
```

`dist` предназначен для обслуживания с одного origin вместе с Rust API.
Прокси Vite работает в dev, не в production. Mock-сборка содержит локальный
демо-адаптер, демонстрационные ответы и выбранные ресурсы в `demo/resources`;
в real-сборке их нет. Оба режима используют одни строгие схемы 2.0.0.
Для работы без внешнего интернета нужны локальная установка/сервер и заранее
установленные зависимости. `file://` не поддерживается.

Service worker сохраняет оболочку, исключая API и потоковые ресурсы мира.
Небольшие настройки графики сохраняются локально; в real баланс, прогресс,
попытки, места и серверные настройки подтверждает сервер.

`npm test` проверяет текущий mock v2 и изолированные регрессии прежнего
клиента. Старые схемы неизменны и доступны только отдельному legacy-модулю
и архивным тестам. `test:integration` сейчас проверяет доменные сценарии
mock v2, а не живой Rust HTTP/WS. Параметр DEV `roomqa` запускает браузерную проверку четырёх кабинетов,
надписей, моделей, взаимодействий, поворота NPC и потокового бюджета.
Свежие визуальные изменения и список ассетов: [room-polish.md](room-polish.md).

## Управление и ограничения

WASD — перемещение, щелчок по сцене и мышь — обзор от первого лица.
E — взаимодействие; Esc освобождает курсор/сворачивает интерфейс.
Из проверки уходят через «Встать и сохранить»: `quiz.leave` сохраняет
`suspended`, продолжение — отдельная команда `quiz.resume`.
За столом соревнования F — встать; во время матча требуется подтверждение.
Ответы передаются как `answer: {kind, value}`, значение — строка.

Переходы между кабинетами сейчас реализованы только mock-адаптером.
В real локальный телепорт отклоняется: в утверждённом контракте нет
команды перехода, серверные координаты нельзя заменять локальными.
Демонстрационная страна не отправляется реальному серверу как настоящий ID.

Лимит `floor(manifest.totalWorldBytes / 10)` проверяет ledger потоковых
ресурсов. Недавний дополнительный слой локальных моделей загружается вне
него; общий предел всех ресурсов сцены поэтому пока **не подтверждён**.
В рамках проверки протокола кастомные модели не менялись.
