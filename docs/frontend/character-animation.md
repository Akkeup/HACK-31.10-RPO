# Походка из демонстрации Polyfork

01.11.2026 программные синусоидальные шаги заменены исходным клипом **Walk**,
который проигрывает просмотрщик Student in a Hoodie из присланного видео.
Это анимация существующего скелета, новый скелет или Blender для неё не нужны.

## Воспроизведение

`reference-walk.js` собирает quaternion tracks тех же 20 костей, которые
использует просмотрщик, и position track для Hips. Суставы пальцев ног,
не включённые в список костей просмотрщика, остаются в исходной позе.
`HumanoidGait` использует интерполянты Three.js: те же SLERP вращений и
линейную интерполяцию смещения, что и AnimationMixer. Коррекция предметов
берётся из `carry*` в extras самой модели, как на сайте.

При 1.1 м/с (обычная прогулка NPC) клип играет с исходной скоростью 1x.
При другой скорости меняется темп воспроизведения пропорционально фактическому
перемещению. Это только визуальная настройка, серверная скорость не меняется.
За 0.2–0.3 с вес походки плавно возрастает или уменьшается. В покое кости
возвращаются в неподвижную исходную позу; посадка по-прежнему отдельная
локальная поза, не анимация из видео. Отключение анимаций соблюдается.

Один набор ключей встроен в клиентский bundle, запросов к Polyfork во время
игры нет. Геометрия GLB не изменена, у каждого персонажа независимые кости.
Анимации, включённые в будущий GLB, по-прежнему имеют приоритет в LocalArt.
Мировые координаты, повороты навигации, коллизии и игровые события не менялись.

## Проверка

`tests/reference-walk.test.js` фиксирует исходные данные по SHA-256,
сравнивает позы семи настоящих моделей с отдельным AnimationMixer на тех же
ключевых и промежуточных кадрах, проверяет темп при 30/60/144 FPS, остановку,
отключение анимаций и посадку. Исходный клип соответствует просмотрщику;
попиксельное совпадение видео зависит также от модели, ракурса и освещения.

`npm run check:release`: 74/74 теста и сборки real/mock прошли.
Локальный замер Node CPU: 60 независимых скелетов, 600 кадров, в среднем
0.173 мс на обновление всех 60 персонажей за кадр после прогрева. Это только
семплирование костей, не замер WebGL/FPS или производительности других ноутбуков.
Браузерный `?roomqa=1` в локальном Firefox: 60 проверок, ошибок нет;
медиана кадра 16.66 мс, p95 17.3 мс (четыре кабинета, затем читальный зал).
Проверка относится к этому компьютеру и сценарию, не ко всем LAN-участникам.
