# Автономный читальный зал

## Запуск

Нужен Node.js 22.12+. Из `apps/client` выполните `npm ci`, затем `npm run dev`.
Откройте `http://127.0.0.1:5173/`. По умолчанию выбран локальный mock-адаптер:
вход, PostgreSQL, LLM, CDN и игровой сервер не нужны. `npm test` проверяет
протокол 2.0.0 и демонстрационные сценарии; `npm run build` собирает демо.

## Модели

Пути и локальные преобразования заданы в `apps/client/src/config/local-art.json`.
Размещение игровых объектов задано в `assets/world/reading-room-layout.json`,
NPC и сидений — в `apps/client/mock-v2/public-config.json`. Изменение модели не
меняет `npcId`, `modelId` или логику взаимодействия. GLB загружаются из
`/assets/models/` только в mock-режиме; каждый файл загружается один раз,
экземпляры клонируются через `SkeletonUtils.clone`. При ошибке остаётся
потоковая геометрическая заглушка.

| Путь после `/assets/models/` | Состояние | Размер (Ш×В×Г) | Анимации |
| --- | --- | --- | --- |
| `npc/teacher.glb` | Есть, один файл для всех тем | 1.67×1.73×0.35 м | Нет |
| `npc/examiner.glb` | Есть | 1.67×1.87×0.65 м | Нет |
| `furniture/bookshelf.glb` | Есть | 2.00×1.85×1.00 м | Нет |
| `furniture/desk.glb` | Есть | 3.00×1.23×1.00 м | Нет |
| `furniture/round-table.glb` | Есть, круглая модель для пяти мест | около 3.14×0.92×3.14 м | Нет |
| `furniture/book.glb` | Отсутствует, заглушка | — | — |
| `furniture/chair.glb` | Отсутствует, заглушка | — | — |
| `furniture/notebook.glb` | Отсутствует, заглушка | — | — |

У персонажей из архива нет клипов idle, walking и sitting. Для учителя и
экзаменатора задана спокойная статичная поза, руки опущены. При замене файла
загрузчик изучает список клипов и использует подходящие анимации через
`AnimationMixer`; независимые скелеты клонируются отдельно. Для полноценной
посадки и ходьбы нужны новые анимированные GLB. Ноги выравниваются по нижней
границе модели на полу. Параметры `scale`, `rotationY` и `offset` меняются в
`local-art.json`; после изменения проверьте проходы и обзор в браузере.

Центральный стол из предоставленного архива продолговатый, поэтому его исходный
файл сохранён в `assets/models/imported`, а для сцены создан круглый стол.
Пересоздать его можно командой `node scripts/create-round-table.js` из
`apps/client`, затем `npm run world:publish` для обновления потокового каталога.

## Игровой сценарий и будущий сервер

WASD и мышь управляют обзором после щелчка в сцене. E открывает ближайший
объект, Esc показывает меню или освобождает курсор; из проверки уходят кнопкой
«Встать и сохранить». Текущая попытка становится `suspended`, а повторное
взаимодействие предлагает продолжить её с тем же вопросом и ответом.

`apps/client/mock-v2/` содержит демонстрационные материалы, ответы, баланс и
виртуальных игроков. Он подключается только в mock-режиме через
`createAdapter()` в `src/network/adapters.js`. Реальный режим выбирается
`VITE_TRANSPORT=real`, но требует отдельного backend по Protocol 2.0.0.
Перед production-публикацией нельзя использовать демонстрационные ключи,
localStorage как источник истины или визуальный слой `/assets/models/` как
замену серверному interest. GLB нужно опубликовать в каталоге с актуальными
SHA-256, byteSize, зависимостями и лимитом. Панель «Бюджет демо» сейчас
показывает только потоковые ресурсы, отдельно от локальных моделей.
